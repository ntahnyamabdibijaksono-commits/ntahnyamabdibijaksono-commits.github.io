Privacy Policy

Effective date: November 24, 2026

This policy explains how the publishing tool of the Pip Science Shorts channel ("Pip Uploader", "we") handles data. The tool is used only by the channel's creator, to upload the channel's own videos to the creator's own accounts.

1. Who uses the tool

Only the channel creator. We do not offer the tool to other people, we have no user sign-up, and we do not collect data from viewers or from any other user.

2. What data we access

  • YouTube (Google): with the creator's permission, the tool uses the YouTube API Services to upload videos, set their titles, descriptions and tags, and read the basic details of the creator's own channel.
  • Facebook (Meta): with the creator's permission, the tool publishes Reels to the creator's own Facebook Page and reads the list of Pages the creator manages.
  • TikTok: with the creator's permission, the tool uploads videos to the creator's own TikTok account and reads basic account information needed to post (such as the display name and posting settings).

We do not access anyone else's account, comments, messages, contacts or viewing history.

3. How we use and store it

Access tokens granted by the creator are stored only on our private server, protected by access controls, and are used for one purpose: publishing the channel's approved videos. We do not sell, share or transfer this data to anyone, and we do not use it for advertising or analytics.

4. YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time on the Google security settings page.

5. Facebook and TikTok

Meta's and TikTok's own data practices are described in the Meta Privacy Policy and the TikTok Privacy Policy. Access can be removed in Facebook settings (Business integrations) and in TikTok settings (Security → Manage app permissions).

6. Data retention and deletion

Tokens are kept only while publishing is active. Revoking access in the platform's settings stops the tool immediately, and we delete the stored token when it is revoked or no longer needed. Video files are deleted from our server after 30 days.

7. This website

This website uses no cookies, no tracking and no analytics. It is hosted on GitHub Pages; GitHub may keep standard server logs as described in the GitHub Privacy Statement.

8. Children

The tool is not directed to children and does not collect data from anyone.

9. Contact

Questions about this policy: contact the creator through the YouTube channel @Pengee30.

10. Changes

We will update this page if the way we handle data changes. The date at the top shows the latest version.
